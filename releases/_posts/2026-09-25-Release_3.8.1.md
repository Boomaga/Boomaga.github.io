Boomaga 3.8.1 is out!
=====================
We are glad to announce a new version of Boomaga. Recent GitHub releases include:

* v3.8.1: adds support for A3
* v3.8.0: includes fixes for a multi-threading crash in Poppler CMS rendering, render worker queue improvements, ARM package builds, and translation updates

See the release notes and changelog here:
* https://github.com/Boomaga/boomaga/releases/tag/v3.8.1
* https://github.com/Boomaga/boomaga/releases/tag/v3.8.0
