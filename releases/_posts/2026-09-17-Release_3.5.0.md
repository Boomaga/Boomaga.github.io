Boomaga 3.5.0 is out!
=====================
We are glad to announce a new version of the boomaga. The most noticeable change are:

* Boomaga now Qt6, and can run on all recently released distros
* Supports latest ghostscript (>9.54)
* A prebuilt .deb package is provided in GitHub releases
* Misc bug fixes. See https://github.com/Boomaga/boomaga/releases/tag/v3.5.0 for more details.
