Boomaga 3.9.0 is out!
=====================
We are glad to announce a new version of Boomaga. This release fixes printing to Boomaga in KDE + Ubuntu.

Recent changes include:

* Fix D-Bus fallback after failed candidate connection
* Prevent potential D-Bus address truncation
* Update credits

See the release notes and changelog here:
* https://github.com/Boomaga/boomaga/releases/tag/v3.9.0
